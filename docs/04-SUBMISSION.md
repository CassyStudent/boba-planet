## Hosting notes

This project is static: there is no build command and no server required in production. Publish index.html, styles.css, app.js, media-config.js, assets/ and media/ together. All site URLs are relative so repository subpaths work. guide.html and docs/ can be included as process evidence. Keep raw/ original masters and intermediate work outside the deployed website. Check your chosen hosting and GitHub file-size limits against the real film. The hosting server should support byte ranges and video/mp4.
